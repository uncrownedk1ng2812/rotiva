## Rotiva とは？

Rotiva はシステムトレイに常駐する小さなアプリです。写真、動画、文書などのファイルをドラッグしている途中で
**Shift** を押すと、カーソルのすぐそばにフォーマットホイールが現れます。変換したい形式を指して離すだけで、
変換されたファイルが元のファイルの隣に保存されます。

オンライン変換サービスへのアップロードも、広告も、待ち時間もありません。

## 使い方

| | ステップ | 詳細 |
|---|---|---|
| **1** | **ファイルをドラッグ** | エクスプローラー、デスクトップ、どのフォルダーからでも。1 つでも複数でも OK。 |
| **2** | **<kbd>Shift</kbd> を押す** | マウスの左ボタンを押したまま。カーソルのすぐそばにホイールが現れます。 |
| **3** | **指してドロップ** | 形式はカーソルの向きで決まるので、セグメントの上にぴったり乗せる必要はありません。中央でドロップするとキャンセルになります。 |

右クリック派ですか？ ホイールの項目はすべて、エクスプローラーの右クリックメニューの
**Rotiva ▸** にもあります（Windows 11 では *その他のオプションを確認*）。

## 対応フォーマット

ホイールはドラッグしたファイルに合わせて変わります。ファイル自身の形式は自動的に非表示になります。

| 種類 | 変換元 | 変換先 |
|---|---|---|
| 🖼️ 画像 | PNG, JPG, WEBP, AVIF, HEIC, BMP, TIFF, GIF, ICO, PSD, SVG, JXL, DNG, CR2, NEF, ARW, … | PNG, JPG, WEBP, AVIF, PDF, ICO, TIFF, **圧縮**, **テキスト (OCR)**, **編集** |
| 🎬 動画 | MP4, MKV, MOV, AVI, WEBM, WMV, FLV, 3GP, MPG, TS, VOB, … | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV, **圧縮**, **編集** |
| 🎵 音声 | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA, AIFF, M4B, AMR, APE, … | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, AIFF, **編集** |
| 📄 文書 | DOCX, DOC, ODT, RTF, TXT, MD, HTML | PDF, DOCX, ODT, TXT, HTML, MD, RTF, EPUB |
| 📊 表計算 | XLSX, XLS, CSV, TSV, ODS | XLSX, CSV, ODS, PDF, XLS, HTML, JSON |
| 📽️ スライド | PPTX, PPT, ODP, PPSX, PPS | PDF, PPTX, ODP, PNG, JPG |
| 📕 PDF | PDF | DOCX, ODT, PNG, JPG, **分割**, **圧縮**, **テキスト (OCR)** |
| 🗜️ アーカイブ | ZIP, RAR, 7Z, TAR.GZ, … | **展開**, ZIP |
| 📚 電子書籍 | EPUB, FB2 | PDF, EPUB, DOCX, HTML, TXT, MD |
| 💬 字幕 | SRT, VTT, ASS, SSA, SMI, LRC | SRT, VTT, ASS, LRC |
| 🧾 データ | JSON, YAML | JSON, YAML, CSV |

## 機能

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4 から MP3、Word から PDF、複数ファイルを 1 つの ZIP に、RAR を一瞬で展開" width="320">
</p>

- **圧縮** — 写真、動画（MP4、最大 1080p）、スキャンした PDF を、形式を変えずに小さくします。
- **1 つの PDF に結合** — 複数の画像、文書、表、PDF をまとめてドラッグ。
- **テキストを取得 (OCR)** — 画像やスキャンした PDF の文字を Windows 標準の OCR で読み取り、そのままクリップボードへ。
- **PDF を分割** — 1 ページずつ別の PDF に、または各ページを PNG/JPG に書き出します。
- **ZIP と展開** — 複数のファイルやフォルダーを 1 つの ZIP に。.zip、.rar、.7z、.tar.gz はワンアクションで展開。
- **編集** — **EDIT** セグメントで 2 ページ目が開きます。画像の回転・反転・グレースケール、動画の回転・反転・逆再生（逆再生は 30 秒まで）、音声の音量均一化・逆再生、カバー画像の保存ができます。
- **字幕の焼き込み** — 動画 1 本と字幕ファイル 1 つを一緒にドラッグして **BURN IN** を選びます。
- **パスワード付き ZIP（Windows）** — **LOCK** でファイルを AES-256 の ZIP にまとめます。7-Zip または WinRAR で開けます。
- **コンタクトシート** — **SHEET** で複数の写真、または動画の 16 フレームを 1 枚の画像にまとめます。
- **クリップボードの変換（Windows）** — ファイルや画像をコピーするかスクリーンショットを撮り、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> を押します。
- **内蔵ガイド（Windows）** — トレイメニューの **Guide** で手順を確認できます。
- **軽くて速い** — ホイールはカーソル位置に開く小さなウィンドウで、全画面エフェクトがないため、4K 画面でも
  すぐに開きます。サイズ（**S / M / L**）はトレイメニューで選べます。
- **やっぱりやめたい？** ホイールの中央に戻って離せば、何も変換されません。
- **100% オフライン** — FFmpeg、ImageMagick、Ghostscript、LibreOffice、Pandoc、7-Zip を同梱。ファイルが PC の外に出ることはありません。

## インストール

1. [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest) から **`Rotiva-Setup-x.y.z.exe`** をダウンロードします。
2. インストーラーを実行します。SmartScreen が表示されたら **詳細情報 → 実行** をクリックしてください
   （インストーラーはまだ有料のコード署名証明書で署名されていません）。
3. システムトレイの Rotiva アイコンを確認したら、ファイルをドラッグして <kbd>Shift</kbd> を押します。

ユーザーごとに `%LOCALAPPDATA%\Programs\Rotiva` へインストールされます。管理者権限も .NET のインストールも不要です。
アンインストール: *設定 → アプリ → インストールされているアプリ → Rotiva*。

トレイアイコンをクリックすると Rotiva のメニューが開きます。Windows 起動時に実行、エクスプローラーの右クリックメニュー、
ホイールのサイズ、ウェブサイト・GitHub・支援へのリンクがあります。

### macOS と Linux

[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest) から **macOS 用 `.dmg`**（Apple Silicon または Intel）か
**Linux 用 `AppImage`** をダウンロードしてください。
ホイールも変換も同じです。ファイルを右クリック → **このアプリケーションで開く → Rotiva**、またはファイルをドラッグして
<kbd>Shift</kbd> を押します。変換エンジンはシステムのものを使います（`brew install …` / `apt install …`）。
コマンドはリリースノートに記載しています。macOS 版はまだ公証（notarize）されていないため、最初に一度だけ
*システム設定 → プライバシーとセキュリティ* で許可してください。

## コード署名

Windows インストーラーはまだコード署名されていないため、初めて実行するときに Windows SmartScreen が警告を表示することがあります。各リリースには SHA-256 チェックサム（`SHA256SUMS.txt`）が含まれており、ダウンロードを確認できます。署名済みの版をご希望の場合は、Microsoft が署名した [Microsoft Store 版](https://apps.microsoft.com/detail/9N5FPM017GN5) をご利用ください。

**プライバシー:** Rotiva はネットワーク上のほかのシステムに一切の情報を送信しません。変換はお使いのコンピューターで
行われます。メニューのリンク（ウェブサイト、GitHub、支援）は、クリックしたときにブラウザーを開くだけです。
