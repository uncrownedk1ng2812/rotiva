## Rotiva คืออะไร?

Rotiva คือแอปเล็ก ๆ ที่อยู่ในถาดระบบ (system tray) ระหว่างที่คุณลากรูปภาพ วิดีโอ เอกสาร หรือไฟล์ใด ๆ
ให้กด **Shift** แล้ววงล้อรูปแบบไฟล์จะปรากฏขึ้นตรงเคอร์เซอร์ทันที ชี้ไปที่รูปแบบที่ต้องการแล้วปล่อย —
ไฟล์ที่แปลงแล้วจะถูกบันทึกไว้ข้าง ๆ ไฟล์ต้นฉบับ

ไม่ต้องอัปโหลดไปยังเว็บแปลงไฟล์ ไม่มีโฆษณา ไม่ต้องรอคิว

## วิธีใช้งาน

| | ขั้นตอน | รายละเอียด |
|---|---|---|
| **1** | **ลากไฟล์** | จาก File Explorer เดสก์ท็อป หรือโฟลเดอร์ใดก็ได้ ไฟล์เดียวหรือหลายไฟล์พร้อมกันก็ได้ |
| **2** | **กด <kbd>Shift</kbd>** | ขณะที่ยังกดเมาส์ซ้ายค้างไว้ วงล้อจะปรากฏตรงเคอร์เซอร์ |
| **3** | **ชี้แล้วปล่อย** | ทิศทางของเคอร์เซอร์จะเป็นตัวเลือกรูปแบบ ไม่จำเป็นต้องวางให้ตรงช่องพอดี ปล่อยตรงกลางเพื่อยกเลิก |

ชอบคลิกขวามากกว่า? ทุกอย่างบนวงล้อยังอยู่ในเมนูคลิกขวาของ File Explorer ใต้
**Rotiva ▸** ด้วย (Windows 11: *Show more options*)

## รูปแบบไฟล์ที่รองรับ

วงล้อจะปรับตามไฟล์ที่คุณลาก รูปแบบเดิมของไฟล์จะถูกซ่อนโดยอัตโนมัติ

| ประเภท | จาก | เป็น |
|---|---|---|
| 🖼️ รูปภาพ | PNG, JPG, WEBP, AVIF, HEIC, BMP, TIFF, GIF, ICO | PNG, JPG, WEBP, AVIF, PDF, ICO, TIFF, **บีบอัด**, **ข้อความ (OCR)** |
| 🎬 วิดีโอ | MP4, MKV, MOV, AVI, WEBM, WMV, FLV, 3GP | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV, **บีบอัด** |
| 🎵 เสียง | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA | MP3, WAV, FLAC, OGG, OPUS, M4A |
| 📄 เอกสาร | DOCX, DOC, ODT, RTF, TXT, MD, HTML | PDF, DOCX, ODT, TXT, HTML, MD, RTF |
| 📊 สเปรดชีต | XLSX, XLS, CSV, TSV, ODS | XLSX, CSV, ODS, PDF, XLS, HTML |
| 📽️ สไลด์ | PPTX, PPT, ODP, PPSX, PPS | PDF, PPTX, ODP, PNG, JPG |
| 📕 PDF | PDF | DOCX, ODT, PNG, JPG, **แยกหน้า**, **บีบอัด**, **ข้อความ (OCR)** |
| 🗜️ ไฟล์บีบอัด | ZIP, RAR, 7Z, TAR.GZ, … | **แตกไฟล์**, ZIP |

## ฟีเจอร์

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4 เป็น MP3, Word เป็น PDF, หลายไฟล์รวมเป็น ZIP เดียว, แตก RAR ได้ทันที" width="320">
</p>

- **บีบอัด** — ลดขนาดรูปภาพ วิดีโอ (MP4 สูงสุด 1080p) และ PDF ที่สแกน โดยไม่เปลี่ยนรูปแบบไฟล์
- **รวมเป็น PDF เดียว** — ลากรูปภาพ เอกสาร สเปรดชีต หรือ PDF หลายไฟล์พร้อมกัน
- **ดึงข้อความ (OCR)** — อ่านข้อความจากรูปภาพหรือ PDF ที่สแกนด้วย OCR ในตัวของ Windows แล้วคัดลอกไปยังคลิปบอร์ดทันที
- **แยก PDF** — แยกเป็น PDF หน้าละไฟล์ หรือส่งออกแต่ละหน้าเป็น PNG/JPG
- **ZIP และแตกไฟล์** — รวมไฟล์และโฟลเดอร์หลายรายการเป็น ZIP เดียว ส่วน .zip, .rar, .7z และ .tar.gz แตกได้ในครั้งเดียว
- **เบาและเร็ว** — วงล้อเป็นหน้าต่างเล็ก ๆ ตรงเคอร์เซอร์ ไม่มีเอฟเฟกต์เต็มจอ จึงเปิดได้ทันทีแม้บนจอ 4K
  เลือกขนาด **S / M / L** ได้จากเมนูในถาดระบบ
- **เปลี่ยนใจ?** กลับไปที่กลางวงล้อแล้วปล่อย: จะไม่มีการแปลงใด ๆ
- **ออฟไลน์ 100%** — มาพร้อม FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc และ 7-Zip ไฟล์ของคุณไม่เคยออกจากเครื่อง

## การติดตั้ง

1. ดาวน์โหลด **`Rotiva-Setup-x.y.z.exe`** จาก [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest)
2. เปิดตัวติดตั้ง หากมี SmartScreen ขึ้นมา ให้คลิก **More info → Run anyway**
   (ตัวติดตั้งยังไม่ได้ลงนามด้วยใบรับรอง code signing แบบเสียเงิน)
3. หาไอคอน Rotiva ในถาดระบบ แล้วลากไฟล์ + กด <kbd>Shift</kbd>

ติดตั้งแยกตามผู้ใช้ไว้ที่ `%LOCALAPPDATA%\Programs\Rotiva` — ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่ต้องติดตั้ง .NET
ถอนการติดตั้งได้ที่ *Settings → Apps → Installed apps → Rotiva*

คลิกไอคอนในถาดระบบเพื่อเปิดเมนู Rotiva: เริ่มพร้อม Windows, เมนูคลิกขวาของ Explorer, ขนาดวงล้อ
และลิงก์ไปยังเว็บไซต์ GitHub และการสนับสนุน

### macOS และ Linux

ดาวน์โหลด **`.dmg` สำหรับ macOS** (Apple Silicon หรือ Intel) หรือ **`AppImage` สำหรับ Linux** จาก
[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest)
วงล้อและการแปลงไฟล์เหมือนกันทุกอย่าง: คลิกขวาที่ไฟล์ → **Open With → Rotiva** หรือลากไฟล์แล้วกด
<kbd>Shift</kbd> เอนจินแปลงไฟล์จะใช้ของระบบ (`brew install …` / `apt install …`) โดยมีคำสั่งอยู่ใน
release notes แอป macOS ยังไม่ได้ผ่าน notarization จึงต้องอนุญาตครั้งแรกใน
*System Settings → Privacy & Security*
