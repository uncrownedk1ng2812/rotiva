## Rotiva क्या है?

Rotiva एक छोटा ऐप है जो सिस्टम ट्रे में रहता है। जब आप कोई फ़ोटो, वीडियो, दस्तावेज़ या कोई भी फ़ाइल
खींच रहे हों, तब **Shift** दबाएँ और कर्सर के ठीक पास एक फ़ॉर्मेट व्हील खुल जाता है। जिस फ़ॉर्मेट में
बदलना है उसकी ओर इशारा करें और छोड़ दें — बदली हुई फ़ाइल मूल फ़ाइल के ठीक बगल में सेव हो जाती है।

ऑनलाइन कन्वर्टर पर अपलोड नहीं, विज्ञापन नहीं, कतार नहीं।

## यह कैसे काम करता है

| | चरण | विवरण |
|---|---|---|
| **1** | **फ़ाइल खींचें** | Explorer, डेस्कटॉप या किसी भी फ़ोल्डर से। एक फ़ाइल या एक साथ कई। |
| **2** | **<kbd>Shift</kbd> दबाएँ** | माउस का बायाँ बटन दबाए रखते हुए। फ़ॉर्मेट व्हील कर्सर के ठीक पास खुलता है। |
| **3** | **इशारा करें और छोड़ें** | फ़ॉर्मेट कर्सर की दिशा से चुना जाता है — किसी हिस्से पर ठीक-ठीक पहुँचना ज़रूरी नहीं। रद्द करने के लिए बीच में छोड़ें। |

राइट-क्लिक पसंद है? व्हील की हर चीज़ Explorer के राइट-क्लिक मेन्यू में **Rotiva ▸** के अंदर भी है
(Windows 11: *Show more options*)।

## सुविधाएँ

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4 से MP3, Word से PDF, कई फ़ाइलें एक ZIP में, RAR तुरंत एक्सट्रैक्ट" width="320">
</p>

- **कंप्रेस** — फ़ोटो, वीडियो (1080p तक MP4) और स्कैन किए गए PDF को फ़ॉर्मेट बदले बिना छोटा करें।
- **1 PDF में जोड़ें** — कई इमेज, दस्तावेज़, स्प्रेडशीट या PDF एक साथ खींचें।
- **टेक्स्ट निकालें (OCR)** — Windows के बिल्ट-इन OCR से किसी इमेज या स्कैन किए गए PDF के शब्द पढ़ें, सीधे क्लिपबोर्ड पर।
- **PDF स्प्लिट करें** — हर पेज की अलग PDF, या हर पेज को PNG/JPG के रूप में एक्सपोर्ट करें।
- **ZIP और एक्सट्रैक्ट** — कई फ़ाइलें/फ़ोल्डर एक ZIP में पैक करें; .zip, .rar, .7z और .tar.gz एक ही बार में एक्सट्रैक्ट।
- **एडिट** — **EDIT** सेगमेंट दूसरा पेज खोलता है: इमेज को घुमाएँ, पलटें या ग्रे करें; वीडियो को घुमाएँ, पलटें या उल्टा चलाएँ (30 सेकंड तक); ऑडियो की आवाज़ बराबर करें, उल्टा करें या कवर आर्ट सेव करें।
- **सबटाइटल बर्न करें** — एक वीडियो और एक सबटाइटल फ़ाइल साथ में ड्रैग करके **BURN IN** चुनें।
- **पासवर्ड वाला ZIP (Windows)** — **LOCK** फ़ाइलों को AES-256 ZIP में पैक करता है। इसे 7-Zip या WinRAR से खोलें।
- **कॉन्टैक्ट शीट** — **SHEET** कई फ़ोटो या वीडियो के 16 फ़्रेम एक ही इमेज में रखता है।
- **क्लिपबोर्ड कन्वर्ट करें (Windows)** — फ़ाइलें या इमेज कॉपी करें या स्क्रीनशॉट लें, फिर <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> दबाएँ।
- **बिल्ट-इन गाइड (Windows)** — चरणों के लिए ट्रे मेनू से **Guide** खोलें।
- **हल्का और तेज़** — व्हील कर्सर के पास एक छोटी विंडो है, बिना फ़ुल-स्क्रीन इफ़ेक्ट के, इसलिए 4K स्क्रीन पर भी
  तुरंत खुलता है। ट्रे मेन्यू से **S / M / L** साइज़ चुनें।
- **मन बदल गया?** व्हील के बीच में वापस जाएँ और छोड़ दें: कुछ भी कन्वर्ट नहीं होगा।
- **100% ऑफ़लाइन** — FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc और 7-Zip साथ में आते हैं। आपकी फ़ाइलें कभी आपके PC से बाहर नहीं जातीं।

## इंस्टॉलेशन

1. [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest) से **`Rotiva-Setup-x.y.z.exe`** डाउनलोड करें।
2. इंस्टॉलर चलाएँ। अगर SmartScreen दिखे, तो **More info → Run anyway** पर क्लिक करें
   (इंस्टॉलर अभी किसी पेड कोड-साइनिंग सर्टिफ़िकेट से साइन नहीं है)।
3. सिस्टम ट्रे में Rotiva का आइकन देखें, फिर कोई फ़ाइल खींचें + <kbd>Shift</kbd> दबाएँ।

हर यूज़र के लिए `%LOCALAPPDATA%\Programs\Rotiva` में इंस्टॉल होता है — एडमिन अधिकार या .NET इंस्टॉल की ज़रूरत नहीं।
अनइंस्टॉल: *Settings → Apps → Installed apps → Rotiva*।

Rotiva मेन्यू के लिए ट्रे आइकन पर क्लिक करें: Windows के साथ शुरू करें, Explorer राइट-क्लिक मेन्यू, व्हील का साइज़,
और वेबसाइट, GitHub व सहयोग के लिंक।

### macOS और Linux

[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest) से **macOS के लिए `.dmg`** (Apple Silicon या Intel) या
**Linux के लिए `AppImage`** डाउनलोड करें।
वही व्हील और वही कन्वर्ज़न: फ़ाइलों पर राइट-क्लिक → **Open With → Rotiva**, या फ़ाइलें खींचें और
<kbd>Shift</kbd> दबाएँ। कन्वर्ज़न इंजन आपके सिस्टम से आते हैं (`brew install …` / `apt install …`); कमांड
रिलीज़ नोट्स में दिए हैं। macOS ऐप अभी notarize नहीं हुआ है, इसलिए पहली बार
*System Settings → Privacy & Security* में उसे अनुमति दें।
