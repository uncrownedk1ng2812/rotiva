## ما هو Rotiva؟

Rotiva تطبيق صغير يعمل من علبة النظام. أثناء سحب صورة أو فيديو أو مستند أو أي ملف آخر، اضغط **Shift**
فتظهر عجلة الصيغ بجوار المؤشر مباشرةً. أشِر إلى الصيغة التي تريدها ثم أفلِت الملف — ويُحفظ الملف المحوَّل
بجانب الملف الأصلي.

لا رفع إلى محوّلات على الإنترنت، ولا إعلانات، ولا انتظار في طوابير.

## كيف يعمل

| | الخطوة | التفاصيل |
|---|---|---|
| **1** | **اسحب ملفًا** | من مستكشف الملفات أو سطح المكتب أو أي مجلد. ملف واحد أو عدة ملفات معًا. |
| **2** | **اضغط <kbd>Shift</kbd>** | مع الاستمرار في الضغط على زر الفأرة الأيسر. تظهر عجلة الصيغ بجوار المؤشر مباشرةً. |
| **3** | **أشِر وأفلِت** | اتجاه المؤشر هو الذي يختار الصيغة — لا داعي للوقوف بدقة على قطعة معيّنة. أفلِت في المنتصف للإلغاء. |

تفضّل النقر بزر الفأرة الأيمن؟ كل ما في العجلة موجود أيضًا في قائمة النقر بزر الفأرة الأيمن في المستكشف، تحت
**Rotiva ▸** (في Windows 11: *Show more options*).

## الصيغ المدعومة

تتغيّر العجلة حسب الملف الذي تسحبه، وتُخفى صيغة الملف نفسه تلقائيًا.

| النوع | من | إلى |
|---|---|---|
| 🖼️ الصور | PNG, JPG, WEBP, AVIF, HEIC, BMP, TIFF, GIF, ICO | PNG, JPG, WEBP, AVIF, PDF, ICO, TIFF, **ضغط**, **نص (OCR)** |
| 🎬 الفيديو | MP4, MKV, MOV, AVI, WEBM, WMV, FLV, 3GP | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV, **ضغط** |
| 🎵 الصوت | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA | MP3, WAV, FLAC, OGG, OPUS, M4A |
| 📄 المستندات | DOCX, DOC, ODT, RTF, TXT, MD, HTML | PDF, DOCX, ODT, TXT, HTML, MD, RTF |
| 📊 جداول البيانات | XLSX, XLS, CSV, TSV, ODS | XLSX, CSV, ODS, PDF, XLS, HTML |
| 📽️ العروض التقديمية | PPTX, PPT, ODP, PPSX, PPS | PDF, PPTX, ODP, PNG, JPG |
| 📕 PDF | PDF | DOCX, ODT, PNG, JPG, **تقسيم**, **ضغط**, **نص (OCR)** |
| 🗜️ الأرشيفات | ZIP, RAR, 7Z, TAR.GZ, … | **فك الضغط**, ZIP |

## المزايا

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4 إلى MP3، وWord إلى PDF، وعدة ملفات في ZIP واحد، وفك RAR فورًا" width="320">
</p>

- **الضغط** — صغّر الصور ومقاطع الفيديو (MP4 حتى 1080p) وملفات PDF الممسوحة ضوئيًا دون تغيير الصيغة.
- **الدمج في ملف PDF واحد** — اسحب عدة صور أو مستندات أو جداول بيانات أو ملفات PDF دفعة واحدة.
- **استخراج النص (OCR)** — اقرأ الكلمات من صورة أو ملف PDF ممسوح ضوئيًا باستخدام OCR المدمج في Windows، مباشرةً إلى الحافظة.
- **تقسيم ملفات PDF** — ملف PDF لكل صفحة، أو صدِّر كل صفحة بصيغة PNG/JPG.
- **ZIP وفك الضغط** — اجمع ملفات ومجلدات كثيرة في ملف ZIP واحد؛ وتُفك ملفات ‎.zip و‎.rar و‎.7z و‎.tar.gz بحركة واحدة.
- **خفيف وسريع** — العجلة نافذة صغيرة بجوار المؤشر بلا مؤثرات ملء الشاشة، لذا تُفتح فورًا حتى على شاشات 4K.
  اختر الحجم **S / M / L** من قائمة علبة النظام.
- **غيّرت رأيك؟** عُد إلى منتصف العجلة وأفلِت: لن يُحوَّل أي شيء.
- **يعمل دون إنترنت 100%** — يأتي مع FFmpeg وImageMagick وGhostscript وLibreOffice وPandoc و7-Zip. ملفاتك لا تغادر جهازك أبدًا.

## التثبيت

1. نزّل **`Rotiva-Setup-x.y.z.exe`** من صفحة [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest).
2. شغّل المثبّت. إذا ظهر SmartScreen فانقر **More info ← Run anyway**
   (المثبّت غير موقّع بعد بشهادة توقيع شيفرة مدفوعة).
3. ابحث عن أيقونة Rotiva في علبة النظام، ثم اسحب ملفًا واضغط <kbd>Shift</kbd>.

يُثبَّت لكل مستخدم في `%LOCALAPPDATA%\Programs\Rotiva` — دون صلاحيات المسؤول ودون الحاجة إلى تثبيت .NET.
لإلغاء التثبيت: *Settings ← Apps ← Installed apps ← Rotiva*.

انقر أيقونة علبة النظام لفتح قائمة Rotiva: التشغيل مع Windows، وقائمة النقر بزر الفأرة الأيمن في المستكشف، وحجم العجلة،
وروابط الموقع وGitHub والدعم.

### macOS وLinux

نزّل **ملف ‎`.dmg` لنظام macOS** (Apple Silicon أو Intel) أو **ملف `AppImage` لنظام Linux** من
[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest).
العجلة والتحويلات نفسها: انقر الملفات بزر الفأرة الأيمن ← **Open With ← Rotiva**، أو اسحب الملفات واضغط
<kbd>Shift</kbd>. تأتي محركات التحويل من نظامك (`brew install …` / `apt install …`)، والأوامر موجودة في ملاحظات
الإصدار. تطبيق macOS لم يخضع للتوثيق (notarization) بعد، لذا اسمح له مرة واحدة من
*System Settings ← Privacy & Security*.

## توقيع الشيفرة

مُثبِّتات Windows غير موقَّعة رقميًا بعد، لذلك قد يعرض Windows SmartScreen تحذيرًا عند تشغيلها أول مرة. يتضمن كل إصدار مجاميع SHA-256 في `SHA256SUMS.txt` لتتحقق من الملف الذي نزّلته. هل تفضّل نسخة موقَّعة؟ Rotiva متوفر أيضًا على [Microsoft Store](https://apps.microsoft.com/detail/9N5FPM017GN5) بتوقيع Microsoft.

**الخصوصية:** لا يرسل Rotiva أي معلومات إلى أنظمة أخرى على الشبكة. تجري التحويلات على حاسوبك، وروابط القائمة
(الموقع وGitHub والدعم) لا تفتح المتصفح إلا عند النقر عليها.
