## Rotiva란?

Rotiva는 시스템 트레이에 상주하는 작은 앱입니다. 사진, 동영상, 문서 등 어떤 파일이든 드래그하는 도중에
**Shift**를 누르면 커서 바로 옆에 포맷 휠이 나타납니다. 원하는 포맷을 가리키고 놓으면, 변환된 파일이
원본 바로 옆에 저장됩니다.

온라인 변환기에 업로드할 필요도, 광고도, 대기열도 없습니다.

## 사용 방법

| | 단계 | 설명 |
|---|---|---|
| **1** | **파일 드래그** | 파일 탐색기, 바탕 화면, 어느 폴더에서든 가능합니다. 파일 하나 또는 여러 개를 한 번에. |
| **2** | **<kbd>Shift</kbd> 누르기** | 마우스 왼쪽 버튼을 계속 누른 상태에서 누릅니다. 커서 바로 옆에 휠이 나타납니다. |
| **3** | **가리키고 놓기** | 커서의 방향으로 포맷이 선택되므로 조각 위에 정확히 올릴 필요가 없습니다. 가운데에서 놓으면 취소됩니다. |

오른쪽 클릭이 더 편하신가요? 휠의 모든 항목은 파일 탐색기 오른쪽 클릭 메뉴의
**Rotiva ▸**에도 있습니다(Windows 11: *추가 옵션 표시*).

## 지원 포맷

휠은 드래그한 파일에 맞게 바뀝니다. 파일 자신의 포맷은 자동으로 숨겨집니다.

| 종류 | 변환 전 | 변환 후 |
|---|---|---|
| 🖼️ 이미지 | PNG, JPG, WEBP, AVIF, HEIC, BMP, TIFF, GIF, ICO, PSD, SVG, JXL, DNG, CR2, NEF, ARW, … | PNG, JPG, WEBP, AVIF, PDF, ICO, TIFF, **압축**, **텍스트 (OCR)**, **편집** |
| 🎬 동영상 | MP4, MKV, MOV, AVI, WEBM, WMV, FLV, 3GP, MPG, TS, VOB, … | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV, **압축**, **편집** |
| 🎵 오디오 | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA, AIFF, M4B, AMR, APE, … | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, AIFF, **편집** |
| 📄 문서 | DOCX, DOC, ODT, RTF, TXT, MD, HTML | PDF, DOCX, ODT, TXT, HTML, MD, RTF, EPUB |
| 📊 스프레드시트 | XLSX, XLS, CSV, TSV, ODS | XLSX, CSV, ODS, PDF, XLS, HTML, JSON |

| 🗜️ 압축 파일 | ZIP, RAR, 7Z, TAR.GZ, … | **압축 풀기**, ZIP |
| 📚 전자책 | EPUB, FB2 | PDF, EPUB, DOCX, HTML, TXT, MD |
| 💬 자막 | SRT, VTT, ASS, SSA, SMI, LRC | SRT, VTT, ASS, LRC |

## 기능

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4를 MP3로, Word를 PDF로, 여러 파일을 ZIP 하나로, RAR 즉시 풀기" width="320">
</p>

- **압축** — 사진, 동영상(MP4 최대 1080p), 스캔한 PDF를 포맷 변경 없이 줄입니다.
- **PDF 하나로 합치기** — 이미지, 문서, 스프레드시트, PDF 여러 개를 한 번에 드래그하세요.
- **텍스트 복사 (OCR)** — 이미지나 스캔한 PDF의 글자를 Windows 내장 OCR로 읽어 바로 클립보드에 넣습니다.
- **PDF 분할** — 페이지마다 별도의 PDF로, 또는 각 페이지를 PNG/JPG로 내보냅니다.
- **ZIP과 압축 풀기** — 여러 파일과 폴더를 ZIP 하나로 묶고, .zip, .rar, .7z, .tar.gz는 한 번에 풉니다.
- **편집** — **EDIT** 세그먼트를 선택하면 두 번째 페이지가 열립니다. 이미지 회전·뒤집기·흑백, 동영상 회전·뒤집기·역재생(역재생은 30초까지), 오디오 음량 평준화·역재생, 커버 이미지 저장을 할 수 있습니다.
- **자막 입히기** — 동영상 하나와 자막 파일 하나를 함께 드래그한 뒤 **BURN IN**을 선택합니다.
- **암호 ZIP (Windows)** — **LOCK**은 파일을 AES-256 ZIP으로 묶습니다. 7-Zip이나 WinRAR로 여세요.
- **콘택트 시트** — **SHEET**는 여러 사진 또는 동영상의 16프레임을 한 장의 이미지로 만듭니다.
- **클립보드 변환 (Windows)** — 파일이나 이미지를 복사하거나 스크린샷을 찍은 뒤 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>를 누릅니다.
- **내장 가이드 (Windows)** — 트레이 메뉴의 **Guide**에서 단계별 안내를 볼 수 있습니다.
- **가볍고 빠름** — 휠은 커서 위치에 열리는 작은 창이고 전체 화면 효과가 없어서, 4K 화면에서도
  즉시 열립니다. 크기(**S / M / L**)는 트레이 메뉴에서 고를 수 있습니다.
- **마음이 바뀌었나요?** 휠 가운데로 돌아가서 놓으면 아무것도 변환되지 않습니다.
- **100% 오프라인** — FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc, 7-Zip이 함께 들어 있습니다. 파일이 PC 밖으로 나가지 않습니다.

## 설치

1. [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest)에서 **`Rotiva-Setup-x.y.z.exe`**를 다운로드합니다.
2. 설치 프로그램을 실행합니다. SmartScreen이 나타나면 **추가 정보 → 실행**을 클릭하세요
   (설치 프로그램은 아직 유료 코드 서명 인증서로 서명되지 않았습니다).
3. 시스템 트레이에서 Rotiva 아이콘을 확인한 뒤, 파일을 드래그하고 <kbd>Shift</kbd>를 누르세요.

사용자별로 `%LOCALAPPDATA%\Programs\Rotiva`에 설치되며, 관리자 권한이나 .NET 설치가 필요 없습니다.
제거: *설정 → 앱 → 설치된 앱 → Rotiva*.

트레이 아이콘을 클릭하면 Rotiva 메뉴가 열립니다. Windows 시작 시 실행, 파일 탐색기 오른쪽 클릭 메뉴, 휠 크기,
웹사이트·GitHub·후원 링크가 있습니다.

### macOS와 Linux

[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest)에서 **macOS용 `.dmg`**(Apple Silicon 또는 Intel)나
**Linux용 `AppImage`**를 다운로드하세요.
휠과 변환 기능은 같습니다. 파일을 오른쪽 클릭 → **다음으로 열기 → Rotiva**, 또는 파일을 드래그하고
<kbd>Shift</kbd>를 누르세요. 변환 엔진은 시스템에 설치된 것을 사용합니다(`brew install …` / `apt install …`).
명령어는 릴리스 노트에 있습니다. macOS 앱은 아직 공증(notarize)되지 않았으므로, 처음 한 번
*시스템 설정 → 개인정보 보호 및 보안*에서 허용해 주세요.

## 오픈 소스

Rotiva는 **GPL-3.0** 오픈 소스입니다. 앱은 [`src/Rotiva`](../../src/Rotiva)(C# / .NET 8 / WPF)에,
설치 프로그램은 [`installer/`](../../installer)에 있습니다. 소스에서 실행하거나 설치 프로그램을 빌드하는 방법은

버그 신고, 아이디어, 풀 리퀘스트는 [Issues](https://github.com/uncrownedk1ng2812/rotiva/issues)에서 언제나 환영합니다.

[SECURITY.md](../../SECURITY.md)에 설명된 대로 비공개로 신고해 주세요.

## 코드 서명

Windows 설치 프로그램은 아직 코드 서명되지 않았으므로 처음 실행할 때 Windows SmartScreen 경고가 표시될 수 있습니다. 각 릴리스에는 다운로드를 확인할 수 있도록 `SHA256SUMS.txt`에 SHA-256 체크섬이 포함되어 있습니다. 서명된 버전을 원하시면 Microsoft가 서명한 [Microsoft Store 버전](https://apps.microsoft.com/detail/9N5FPM017GN5)을 이용하세요.

**개인정보:** Rotiva는 네트워크의 다른 시스템으로 어떤 정보도 보내지 않습니다. 변환은 사용자의 컴퓨터에서
이루어지며, 메뉴의 링크(웹사이트, GitHub, 후원)는 클릭할 때만 브라우저를 엽니다.
