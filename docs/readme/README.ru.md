## Что такое Rotiva?

Rotiva — небольшая программа, которая живёт в области уведомлений. Пока вы перетаскиваете фото, видео,
документ или любой другой файл, нажмите **Shift** — прямо у курсора появится колесо форматов. Наведите на нужный
формат и отпустите: сконвертированный файл сохранится рядом с оригиналом.

Никакой загрузки в онлайн-конвертеры, никакой рекламы, никаких очередей.

## Как это работает

| | Шаг | Подробности |
|---|---|---|
| **1** | **Перетащите файл** | Из Проводника, с рабочего стола или из любой папки. Один файл или сразу несколько. |
| **2** | **Нажмите <kbd>Shift</kbd>** | Не отпуская левую кнопку мыши. Колесо форматов появится прямо у курсора. |
| **3** | **Наведите и отпустите** | Формат выбирается направлением курсора — точно попадать в сегмент не нужно. Отпустите в центре, чтобы отменить. |

Привыкли к правой кнопке мыши? Всё, что есть на колесе, есть и в контекстном меню Проводника, в разделе
**Rotiva ▸** (Windows 11: *Показать дополнительные параметры*).

## Поддерживаемые форматы

Колесо подстраивается под перетаскиваемый файл. Собственный формат файла скрывается автоматически.

| Тип | Из | В |
|---|---|---|
| 🖼️ Изображения | PNG, JPG, WEBP, AVIF, HEIC, BMP, TIFF, GIF, ICO | PNG, JPG, WEBP, AVIF, PDF, ICO, TIFF, **Сжать**, **Текст (OCR)** |
| 🎬 Видео | MP4, MKV, MOV, AVI, WEBM, WMV, FLV, 3GP | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV, **Сжать** |
| 🎵 Аудио | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA | MP3, WAV, FLAC, OGG, OPUS, M4A |
| 📄 Документы | DOCX, DOC, ODT, RTF, TXT, MD, HTML | PDF, DOCX, ODT, TXT, HTML, MD, RTF |
| 📊 Таблицы | XLSX, XLS, CSV, TSV, ODS | XLSX, CSV, ODS, PDF, XLS, HTML |
| 📽️ Презентации | PPTX, PPT, ODP, PPSX, PPS | PDF, PPTX, ODP, PNG, JPG |
| 📕 PDF | PDF | DOCX, ODT, PNG, JPG, **Разделить**, **Сжать**, **Текст (OCR)** |
| 🗜️ Архивы | ZIP, RAR, 7Z, TAR.GZ, … | **Распаковать**, ZIP |

## Возможности

<p align="center">
  <img src="../../assets/readme/features.gif" alt="MP4 в MP3, Word в PDF, много файлов в один ZIP, RAR распакован мгновенно" width="320">
</p>

- **Сжатие** — уменьшайте фото, видео (MP4 до 1080p) и отсканированные PDF без смены формата.
- **Объединить в 1 PDF** — перетащите сразу несколько изображений, документов, таблиц или PDF.
- **Скопировать текст (OCR)** — распознавайте текст на изображении или в отсканированном PDF встроенным OCR Windows, сразу в буфер обмена.
- **Разделение PDF** — по одному PDF на страницу или экспорт каждой страницы в PNG/JPG.
- **ZIP и распаковка** — упакуйте много файлов и папок в один ZIP; .zip, .rar, .7z и .tar.gz распаковываются одним движением.
- **Лёгкая и быстрая** — колесо — это маленькое окно у курсора без полноэкранных эффектов, поэтому оно открывается
  мгновенно даже на 4K-экранах. Размер **S / M / L** выбирается в меню значка в трее.
- **Передумали?** Верните курсор в центр колеса и отпустите: ничего не будет сконвертировано.
- **100% офлайн** — FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc и 7-Zip уже в комплекте. Ваши файлы никогда не покидают компьютер.

## Установка

1. Скачайте **`Rotiva-Setup-x.y.z.exe`** со страницы [Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest).
2. Запустите установщик. Если появится SmartScreen, нажмите **Подробнее → Выполнить в любом случае**
   (установщик пока не подписан платным сертификатом подписи кода).
3. Найдите значок Rotiva в области уведомлений и перетащите файл + <kbd>Shift</kbd>.

Устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\Rotiva` — без прав администратора и без установки .NET.
Удаление: *Параметры → Приложения → Установленные приложения → Rotiva*.

Нажмите на значок в трее, чтобы открыть меню Rotiva: запуск вместе с Windows, контекстное меню Проводника,
размер колеса и ссылки на сайт, GitHub и поддержку.

### macOS и Linux

Скачайте **`.dmg` для macOS** (Apple Silicon или Intel) или **`AppImage` для Linux** со страницы
[Releases](https://github.com/uncrownedk1ng2812/rotiva/releases/latest).
То же колесо и те же конвертации: правый клик по файлам → **Открыть в программе → Rotiva** или перетащите файлы
и нажмите <kbd>Shift</kbd>. Движки конвертации берутся из системы (`brew install …` / `apt install …`); команды
указаны в описании релиза. Приложение для macOS пока не нотаризовано, поэтому один раз разрешите его в
*Системных настройках → Конфиденциальность и безопасность*.

## Open source

Rotiva распространяется как open source по лицензии **GPL-3.0**. Приложение находится в [`src/Rotiva`](../../src/Rotiva)
(C# / .NET 8 / WPF), установщик — в [`installer/`](../../installer). Как запустить из исходников или собрать установщик,
описано в [BUILDING.md](../../BUILDING.md).

Сообщения об ошибках, идеи и pull request'ы приветствуются в [Issues](https://github.com/uncrownedk1ng2812/rotiva/issues);
см. [CONTRIBUTING.md](../../CONTRIBUTING.md) и [Кодекс поведения](../../CODE_OF_CONDUCT.md). О проблемах безопасности
сообщайте конфиденциально, как описано в [SECURITY.md](../../SECURITY.md).

## Политика подписи кода

Установщики для Windows собираются из этого репозитория
[workflow установщика Windows](../../.github/workflows/windows-installer.yml) и подписываются там же; ничего, собранного
в другом месте, не подписывается. Бесплатная подпись кода предоставлена [SignPath.io](https://about.signpath.io),
сертификат — [SignPath Foundation](https://signpath.org). Подробности в
[README на английском](../../README.md#code-signing-policy).

**Конфиденциальность:** Rotiva не передаёт никакую информацию другим системам в сети. Конвертация выполняется на вашем
компьютере; ссылки в меню (сайт, GitHub, поддержка) открывают браузер только при нажатии.
