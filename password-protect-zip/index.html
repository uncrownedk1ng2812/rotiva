How to Password Protect a ZIP File on Windows (AES-256, Free)

Windows' built-in ZIP tool has no password option. Rotiva adds one: drag a file, press Shift, pick LOCK, and type a password. The result is a standard AES-256 ZIP.

How to do it (3 steps)

  1. Select one or more files and start dragging them.
  2. Press Shift while you keep holding the mouse button.
  3. Point at LOCK, let go, and enter a password. The encrypted ZIP is saved next to the originals.

New to Rotiva? Install it, then look for the wheel icon in the system tray.

Opening the locked ZIP

Use 7-Zip or WinRAR. Windows File Explorer may not open AES-256 ZIP files, so tell the person you send it to.

Choosing a password

Use plain Latin letters, numbers and common symbols. A longer password is stronger. Send it through a different channel from the file, and keep a copy: a lost password cannot be recovered.

Frequently asked questions

Is LOCK available on macOS and Linux?

Not yet. LOCK is Windows only.

Are the original files deleted?

No. Rotiva creates a new ZIP and leaves the originals alone. Delete them yourself if only the locked copy should remain.
