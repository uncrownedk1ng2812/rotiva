Cara Convert Word ke PDF di Laptop Tanpa Microsoft Word (Gratis)

Tugas kuliah, surat lamaran atau laporan kantor sering harus dikirim dalam bentuk PDF. Biasanya kamu buka Word, klik Save As, pilih PDF… Dengan Rotiva cukup drag file-nya dan pilih PDF — bahkan di PC yang tidak punya Microsoft Word.

Caranya (3 langkah)

  1. Drag file DOCX atau DOC.
  2. Tekan Shift sambil tetap menahan klik.
  3. Arahkan ke PDF lalu lepas. PDF-nya muncul di folder yang sama.

Tidak punya Microsoft Office?

Rotiva sudah membawa LibreOffice di dalamnya (bisa dipilih saat instalasi), jadi konversi dokumen tetap jalan walaupun Word tidak ter-install atau lisensinya sudah habis.

Gabung beberapa dokumen jadi satu PDF

Drag beberapa file Word, gambar atau PDF sekaligus, tekan Shift, lalu pilih MERGE. Semuanya digabung jadi satu PDF — cocok untuk berkas lamaran kerja (CV, surat lamaran, scan ijazah) yang harus dikirim dalam satu file.

Format dokumen lain

ODT, RTF, TXT, Markdown dan HTML juga bisa diubah ke PDF, DOCX atau sebaliknya.

Pertanyaan umum

Apakah tata letaknya berubah?

Untuk dokumen biasa (teks, tabel, gambar) hasilnya sama dengan aslinya. Font yang tidak ter-install di PC bisa diganti dengan font yang mirip.

Dokumen saya rahasia, aman?

Aman. Dokumen tidak di-upload ke mana pun — semuanya diproses di PC kamu.
