Cara Extract File RAR, 7Z & ZIP di Laptop Tanpa WinRAR (Gratis)

Download file RAR atau 7Z tapi Windows tidak bisa membukanya? Daripada install WinRAR yang terus mengingatkan masa trial, Rotiva bisa mengekstrak RAR, 7Z, ZIP dan TAR.GZ langsung ke sebuah folder.

Caranya (3 langkah)

  1. Drag file RAR, 7Z, ZIP atau TAR.GZ.
  2. Tekan Shift sambil tetap menahan klik.
  3. Arahkan ke EXTRACT lalu lepas. Isinya muncul di folder baru di sebelah file aslinya.

Belum punya Rotiva? Download gratis di bawah, install, lalu cari ikon roda di system tray.

Mesin 7-Zip di dalamnya

Rotiva membawa 7-Zip, jadi hampir semua format arsip bisa dibuka: RAR, 7Z, ZIP, TAR, GZ, TGZ, BZ2 dan XZ.

Bikin ZIP juga bisa

Mau mengirim banyak file sekaligus? Pilih semua file atau folder, drag, tekan Shift, lalu pilih ZIP. File ZIP bisa dibuka di PC mana pun tanpa aplikasi tambahan.

Pertanyaan umum

Bisa membuat file RAR?

Tidak. Format RAR milik WinRAR dan alat pembuatnya tidak boleh disertakan di aplikasi lain. Rotiva membuat ZIP, yang lebih universal.

Lewat klik kanan bisa?

Bisa: klik kanan file → Rotiva ▸ → Extract. Di Windows 11 ada di Show more options.
