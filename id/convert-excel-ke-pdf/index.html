Cara Convert Excel ke PDF di Laptop Tanpa Microsoft Excel (Gratis)

Laporan keuangan, daftar nilai atau invoice dari Excel sering harus dikirim sebagai PDF supaya tampilannya tidak berubah di komputer lain. Rotiva mengubah Excel ke PDF langsung dari Explorer, bahkan di PC yang tidak punya Microsoft Office.

Caranya (3 langkah)

  1. Drag file XLSX atau XLS.
  2. Tekan Shift sambil tetap menahan klik.
  3. Arahkan ke PDF lalu lepas. PDF-nya tersimpan di sebelah file Excel.

Tanpa Microsoft Office

Konversi spreadsheet memakai LibreOffice Calc yang sudah termasuk di installer Rotiva. Pastikan komponen Document & Excel/CSV spreadsheet conversion tercentang saat instalasi (default-nya tercentang).

Gabung beberapa Excel jadi satu PDF

Drag beberapa file Excel (boleh dicampur dengan Word, foto atau PDF), tekan Shift, pilih MERGE — semuanya jadi satu PDF.

Format spreadsheet lain

XLSX, XLS, CSV, TSV dan ODS bisa diubah satu sama lain, ke PDF, atau ke tabel HTML.

Pertanyaan umum

Apakah rumus dan format ikut?

PDF menampilkan hasil rumus beserta format sel (warna, border, angka) seperti yang terlihat di spreadsheet.

Apakah data saya aman?

Ya. Spreadsheet diproses di PC kamu, tidak di-upload ke mana pun.
