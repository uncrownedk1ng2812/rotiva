Cara Gabung PDF, Foto & Word Jadi 1 PDF di Laptop (Gratis)

Berkas lamaran kerja, pendaftaran kampus atau laporan sering harus dikirim dalam satu file PDF: CV, surat lamaran, scan KTP, ijazah dan transkrip. Dengan Rotiva semuanya bisa digabung sekaligus.

Caranya (3 langkah)

  1. Pilih semua file (PDF, JPG, PNG, DOCX, …) di Explorer, lalu drag bersamaan.
  2. Tekan Shift sambil tetap menahan klik.
  3. Arahkan ke MERGE lalu lepas. Satu PDF gabungan langsung jadi.

Campur jenis file

Kamu tidak perlu mengubah foto atau Word ke PDF dulu. Rotiva otomatis mengonversi setiap file lalu menggabungkannya jadi satu PDF.

Kebalikannya: pecah PDF

Butuh halaman tertentu saja? Drag PDF, tekan Shift, pilih SPLIT — setiap halaman jadi satu PDF tersendiri di sebuah folder.

Pertanyaan umum

Urutan halamannya bagaimana?

Urutan mengikuti nama file. Supaya urutannya pas, beri nomor di depan nama file, misalnya 1 CV.pdf, 2 Surat lamaran.docx, 3 KTP.jpg.

Hasilnya terlalu besar?

Drag PDF gabungannya lalu pilih COMPRESS untuk memperkecil ukurannya.
