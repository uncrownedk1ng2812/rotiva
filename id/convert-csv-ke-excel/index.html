Cara Convert CSV ke Excel (XLSX) di Laptop, Angka Tidak Berantakan

File CSV hasil export dari marketplace, aplikasi kasir atau internet banking sering berantakan saat dibuka di Excel: semua kolom menumpuk di kolom A, atau angka 1.500,50 terbaca salah. Rotiva mengubah CSV jadi XLSX yang rapi.

Caranya (3 langkah)

  1. Drag file CSV atau TSV.
  2. Tekan Shift sambil tetap menahan klik.
  3. Arahkan ke XLSX lalu lepas. File Excel siap dibuka.

Format angka Indonesia

CSV yang dipisah titik koma biasanya memakai koma sebagai desimal (misalnya 1500,5). Rotiva mengenali format ini, jadi angkanya tetap terbaca sebagai angka, bukan teks.

Sebaliknya: Excel ke CSV

Butuh CSV untuk di-upload ke sistem lain? Drag file XLSX lalu pilih CSV. CSV hanya berisi satu sheet, jadi yang diambil sheet pertama.
