FAQ

Apakah gratis?

Ya — gratis, tanpa batas dan tanpa iklan.

Kenapa muncul peringatan SmartScreen?

Installer-nya belum ditandatangani dengan sertifikat code-signing berbayar, jadi Windows belum "mengenali" penerbitnya. Aman — klik More info, lalu Run anyway.

Apakah file saya di-upload ke suatu tempat?

Tidak. Semua konversi berjalan di PC kamu memakai mesin yang sudah termasuk (FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc, 7-Zip). OCR memakai fitur bawaan Windows.

Bisa bikin file RAR?

Bisa membuka (ekstrak) file RAR, tapi tidak bisa membuatnya: format itu milik WinRAR dan alat pembuatnya tidak boleh disertakan di aplikasi lain. Rotiva membuat file ZIP, yang bisa dibuka di PC mana pun tanpa software tambahan.

Di mana file hasil konversi disimpan?

Di folder yang sama dengan file aslinya. File asli tidak pernah diubah; kalau namanya sudah dipakai, hasilnya diberi nomor, misalnya foto (1).png.

Rodanya tidak muncul saat saya tekan Shift.

Pastikan ikon Rotiva ada di system tray dan kamu menekan Shift sambil masih men-drag file (tombol kiri mouse tetap ditahan). Folder dan jenis file yang tidak didukung hanya mendapat roda kecil berisi ZIP.

Bagaimana supaya otomatis jalan saat Windows menyala?

Centang opsinya saat instalasi, atau klik kanan ikon tray → Start with Windows.

Bagaimana cara uninstall?

Settings → Apps → Installed apps → Rotiva → Uninstall. Menu klik kanan dan autostart-nya ikut terhapus.
