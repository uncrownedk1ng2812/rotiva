Coba langsung di sini

Drag salah satu file di bawah, tekan Shift sambil masih menahan klik, arahkan ke format, lalu lepas.

Roda menyesuaikan file yang kamu drag

Enam kategori, puluhan format sumber. Format yang sama dengan file asli otomatis disembunyikan.

Bukan cuma ganti ekstensi

Kompres

Perkecil foto, video (MP4 maks. 1080p), dan PDF hasil scan (150 dpi) tanpa ganti format.

Gabung jadi 1 PDF

Drag beberapa gambar, dokumen, tabel, atau PDF sekaligus — segmen GABUNG muncul otomatis.

Ambil teks (OCR)

Segmen TEKS membaca tulisan dari gambar atau PDF scan pakai OCR bawaan Windows — langsung masuk clipboard.

Pisah PDF

Satu PDF jadi PDF per halaman, atau ekspor semua halaman jadi PNG/JPG dalam satu folder.

100% offline

FFmpeg, ImageMagick, Ghostscript, LibreOffice & Pandoc sudah dibundel. File tidak pernah keluar dari PC kamu.

Antre di background

Hasil disimpan di samping file asli, progresnya tampil di notifikasi kecil. Kerjaanmu tidak terganggu.

Lebih suka klik kanan? Juga bisa.

Semua pilihan di roda juga ada di menu klik kanan Explorer, di bawah Rotiva ▸. Di Windows 11 ada di Show more options (Shift+F10). Bisa dimatikan dari ikon tray.

Kenapa muncul peringatan SmartScreen?

Installer belum ditandatangani sertifikat code-signing berbayar, jadi Windows belum "mengenal" penerbitnya. Klik More info lalu Run anyway.

Apakah file saya diunggah ke internet?

Tidak. Semua konversi berjalan di PC kamu memakai engine yang ikut terpasang (FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc). OCR memakai fitur bawaan Windows.

Hasil konversinya disimpan di mana?

Di folder yang sama dengan file aslinya. File asli tidak diubah; kalau nama sudah dipakai, hasil diberi nomor seperti foto (1).png.

Rodanya tidak muncul saat tekan Shift.

Pastikan ikon Rotiva ada di system tray dan kamu menekan Shift sambil masih men-drag file (klik kiri masih ditahan). Jenis file yang tidak didukung, termasuk folder, tidak memunculkan roda.

Bagaimana supaya jalan otomatis saat Windows menyala?

Centang opsi saat instalasi, atau klik kanan ikon tray → Jalankan saat Windows menyala.

Cara uninstall?

Settings → Apps → Installed apps → Rotiva → Uninstall. Menu klik kanan dan autostart ikut dibersihkan.
