FAQ

Is it free?

Yes — free, unlimited and ad-free.

Why does SmartScreen show a warning?

The installer isn't signed with a paid code-signing certificate yet, so Windows doesn't "recognize" the publisher. Click More info, then Run anyway.

Are my files uploaded anywhere?

No. Every conversion runs on your PC using the bundled engines (FFmpeg, ImageMagick, Ghostscript, LibreOffice, Pandoc, 7-Zip). OCR uses the feature built into Windows.

Can it create RAR files?

It can open (extract) RAR files, but not create them: the format belongs to WinRAR and its creation tool can't be bundled with other apps. Rotiva creates ZIP files, which open on any PC without extra software.

Where are converted files saved?

In the same folder as the original. The original is never modified; if the name is taken, the result gets a number, like photo (1).png.

The wheel doesn't appear when I press Shift.

Make sure the Rotiva icon is in the system tray and that you press Shift while still dragging the file (left button held down). Folders and unsupported file types get a small wheel with ZIP only.

How do I make it start with Windows?

Tick the option during setup, or right-click the tray icon → Start with Windows.

How do I uninstall it?

Settings → Apps → Installed apps → Rotiva → Uninstall. The right-click menu and autostart entry are removed too.
